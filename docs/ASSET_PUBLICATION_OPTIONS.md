# 资产分发方式

2026-10-03 项目负责人确定沿用 DexJoCo 的许可说明结构和模型随包提供方式。当前代码和数据仓库仍保持私有；这项选择不改变公开状态。

## 当前采用的方式

- 原创代码采用 MIT；继承代码保留上游版权声明和许可证。
- 七手六任务所需机器人模型、任务物体、网格和纹理全部随本项目源码及 wheel 提供。801 个必要文件约 252 MB，均为实际文件。
- 第三方资产保留已有条款、署名、固定上游版本、文件校验值及修改记录，不统一重新授权为 MIT。
- 原创示范数据贡献采用 CC BY-NC-SA 4.0，适用范围见 [数据许可](../dataset/LICENSE_SCOPE.md)。第三方素材及相关权利保留各自条款，论文继续采用 CC BY 4.0。

模型随包安装已通过验收，详见 [随包资产验收](BUNDLED_ASSET_VALIDATION.md)。补充数据许可后，947 个运行文件与已验证版本逐字节一致，801 个必要资产校验值不变；记录见 [许可应用检查](DATASET_LICENSE_APPLICATION.json)。

## 来源与许可记录

参照 [DexJoCo 的公开说明](https://github.com/brave-eai/dexjoco#-license)，原创代码许可与第三方组件、资产条款分别说明。完整记录保留在 [第三方说明](../THIRD_PARTY_NOTICES.md)、[许可状态](../LICENSE_STATUS.md) 和 [运行资产报告](ASSET_RELEASE_REPORT.json)。

282 个来源已确认但许可范围未确认的条目继续如实保留，其中 DexJoCo 来源 225 个、UniDex 来源 57 个。此分发决定不构成第三方权利人的新授权，也不将这些条目改成已确认许可。尚未向上游作者发送联系消息。

## 后续发布工作

沿用当前冻结模型和完整打包方案。论文已在 [arXiv:2610.03278](https://arxiv.org/abs/2610.03278) 正式公布，官方链接及引用已补充；代码和数据的公开状态按项目负责人此前暂停公开的要求保持私有，待明确公开指令后调整。
