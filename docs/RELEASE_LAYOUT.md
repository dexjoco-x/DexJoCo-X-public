# 发布候选范围

本地候选使用独立 Git 历史，不继承原私有仓库提交。

- Git 源码：七手六任务仿真与成功规则、必要模型资产、数据索引和下载/转换工具、评测协议、动作表征接口、π0.5 推理示例及场景扩增工具。
- Hugging Face 数据：六个任务 TAR 包，完整 2,100 条原生示范，固定版本并逐文件校验。
- 外部组件：使用者自己的模型训练框架、策略 checkpoint、tokenizer 和可选 DexLatent 编码器。
- 私有保留：本项目模型训练实现与补丁、全部权重、手套映射、校准、实时输入桥接、内部训练记录与旧 Git 历史。

项目原创代码采用 MIT，第三方条款及署名随文件保留。数据的最终公开许可另行确认。GitHub 发布仓库已同步本候选的独立历史，旧版本作本地镜像备份；本次同步不改变任何远端仓库可见性。
