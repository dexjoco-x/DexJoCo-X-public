# Hugging Face 数据仓库整理记录

## 当前发现

数据仓库 `darenrenjian/DexJoCo-X` 目前保持私有。检查版本 `262bcd30eb80e832bb6af04910358f804cefb5b9` 发现，旧上传范围除了示范，还包含：

- `representation_codecs/table1_sided_v3/codecs/selected.pt`：DexLatent 编码器权重。
- `tools/beingh_train_entry.py`、`tools/check_adapters.py` 等旧工具和动作头扩展检查。
- 重复的转换源码、私有训练验收记录和 vendor 文件。

这些内容不在六个任务 TAR 包中。当前按任务下载仍按白名单取得原始示范，但将整个数据仓库改为公开后，旧提交中的文件也可能被直接下载。因此只从 `main` 删除文件不足以隔离旧权重。

代码、转换和推理入口统一由 GitHub 发布仓库提供。数据仓库不再附带 `.py` 工具、训练记录或 `representation_codecs/` 编码器目录。新数据卡不授予尚未确定的公开数据许可，不填写未经确认的论文作者或引用。

3. 更新 GitHub 下载索引的原始数据与 TAR 固定 revision，重新校验单任务下载、全量索引和 XHand 修正记录。
4. 原归档和新仓库均保持私有。公开需要项目负责人另行明确指示。

旧仓库完整保留在私有 `darenrenjian/DexJoCo-X-private-archive-20261002`，未删除任何旧提交。新的私有 `darenrenjian/DexJoCo-X` 包含 11,525 个文件，其中 11,513 个为下载索引中的原始数据/元数据，另含六个 TAR 包及数据卡与校验文件。全部远端文件已与独立本地副本进行 LFS SHA-256 或 Git blob 校验。
