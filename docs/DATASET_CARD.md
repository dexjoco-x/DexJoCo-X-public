# DexJoCo-X 数据卡

## 范围

数据集覆盖七种代表性灵巧手、六个单臂/双臂任务，共 42 个组合、2,100 条示范、946,156 帧。每个组合 50 条，全部为训练数据，采样频率为 20 Hz。评测使用独立场景种子。

手型包括 Allegro、Inspire、LEAP、LinkerHand、Sharpa Wave、Wuji 和 XHand。任务及内部键见根目录 README。

## 交付内容

六个 TAR 包共 8.242 GB，每包一个任务、350 条示范。包内为原生 state/action 张量、有效维掩码、256×256 H.264 视频、任务/控制合约、来源索引与修正证据。所有条目都是普通文件，没有软链接或硬链接条目。

包中不包含策略权重、编码器权重、手套映射、模型训练实现或预转换训练缓存。必要的仿真模型资产随代码候选另行提供。

使用者可从原始数据生成 Native 与 FAAS 的 200 维 Parquet/视频视图。DexLatent 转换另需自备兼容的编码器及匹配记录。输出只覆盖已安装任务；完整六任务转换覆盖全部 42 个组合。字段、单位、排列和归一化见 [数据接口](../dataset/README.md)。

## 修订与完整性

`dataset-v1.0-corrected` 替换了 XHand 微波炉任务的 50 条轨迹，安装修订号为 `xhand_left_mount_rx180_v1`；其余 2,050 条继承自冻结数据。历史论文 checkpoint 与当前修正数据分版本记录。

下载索引绑定固定 Hugging Face revision、归档及逐文件 SHA-256。工具下载后检查哈希并安全解压。数据集已公开，无需登录即可下载；代码仓库保持私有。
