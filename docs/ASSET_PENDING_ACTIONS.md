# 资产来源与条款记录

正式 42 个模型引用 661 个不同素材文件：303 个有已记录许可，76 个 Inspire 网格按 CC BY-NC-SA 4.0 记录，282 个第三方文件的资产许可范围尚未确认。

这 282 个文件已匹配到 DexJoCo（225 个）与 UniDex（57 个）的固定版本。来源匹配、原许可与修改证据见 ASSET_SOURCE_MATCHES.json、ASSET_RELEASE_REPORT.json 以及 licenses/third_party。来源匹配不表示取得了新的单独授权。

本候选保留运行所需的冻结模型几何及相关记录，当前仍为私有。数据的 RGB 渲染包含这些模型与纹理；原创示范的许可与第三方适用条款需分别记录。

`python tools/asset_release_report.py` 可重新核对完整性。`--require-ready` 仍会因未确认条款返回失败，文件完整性与许可核验完整性分别报告。
