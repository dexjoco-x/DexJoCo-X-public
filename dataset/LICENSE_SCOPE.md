# DexJoCo-X dataset license scope

**Selected on October 3, 2026.** Original dataset contributions are licensed as described below. Code and data repositories remain private until publication is explicitly requested.

## Original dataset contributions

The license for original DexJoCo-X dataset contributions is **Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International (CC BY-NC-SA 4.0)**. It applies only to copyright and database rights that the DexJoCo-X contributors own or are authorized to license in the demonstration records, dataset organization, annotations, and metadata.

The dataset contains 2,100 training demonstrations across seven dexterous hands and six tasks. The license permits noncommercial sharing and adaptation of the licensed contributions, with attribution, a license link, and an indication of changes. Distributed adaptations of licensed material must use the same or a compatible license, as specified by the standard legal code.

Attribution information:

- Dataset: DexJoCo-X, `dataset-v1.0-corrected`.
- Creators: Xiangwei Jiang, Yao Mu, Lixin Duan, Wen Li.
- Project: https://darenrenjian.github.io/DexJoCo-X-website/
- Dataset: https://huggingface.co/datasets/darenrenjian/DexJoCo-X
- License: https://creativecommons.org/licenses/by-nc-sa/4.0/

The standard legal code is supplied unchanged in [CC-BY-NC-SA-4.0.txt](CC-BY-NC-SA-4.0.txt). Citation of the associated paper is recommended for academic use; this request adds no license conditions.

## Third-party material

Robot models, object meshes, textures, and any third-party rights in their rendered appearances retain their applicable terms. These rights are not relicensed by this notice. Records of sources, modifications, and available licenses are maintained with the evaluation environment in `THIRD_PARTY_NOTICES.md`, `LICENSE_STATUS.md`, and `docs/ASSET_RELEASE_REPORT.json`.

Some third-party asset license scopes remain unconfirmed. This data license does not supply missing permissions for those assets or establish that all rights in every RGB frame have been cleared.

## Separate materials

Original benchmark code uses MIT within its documented scope. The paper uses CC BY 4.0. Strategy weights, codec weights, glove mappings, and internal training implementations are outside this dataset distribution.
