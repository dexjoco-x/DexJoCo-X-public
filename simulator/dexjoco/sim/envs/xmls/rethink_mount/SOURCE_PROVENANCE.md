# Rethink mount provenance

`pedestal.stl` is byte-identical to RoboSuite 1.4.1
`models/assets/mounts/meshes/rethink_mount/pedestal.stl`. The RoboSuite MIT
license is retained as `SOURCE_LICENSE_ROBOSUITE`.

The local OBJ, MTL, and DAE files appear to be converted representations used
by the benchmark, but this audit has not recovered the conversion receipt.
They should be treated as source-derived files pending project-owner
confirmation.
