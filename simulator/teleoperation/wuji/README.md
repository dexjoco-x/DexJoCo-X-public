# Wuji Teleoperation

This package is the dedicated home for Wuji teleoperation code.

## Current Status

- canonical `wuji_right` profile is frozen as a 20D qpos layout
- local UniDex Wuji right-hand URDF / mesh assets are copied under `assets/right/`
- Panda-mounted Wuji XML is generated by `tools/generate_panda_wuji_xml.py`
- `hammer_nail_wuji` is registered for DexJoCo recording
- `bridge/send_wuji_qpos_udp.py` forwards Windows Rokoko/glove input to 20D Wuji qpos
- `viewers/retarget_eval_mujoco_wuji.py` provides a standalone 20D qpos viewer
- `bridge/send_wuji_test_qpos_udp.py` provides a simple UDP qpos smoke-test sender

## Commands

Regenerate the Panda-mounted XML:

```bash
python teleoperation/wuji/tools/generate_panda_wuji_xml.py
```

Standalone qpos viewer:

```bash
python teleoperation/wuji/viewers/retarget_eval_mujoco_wuji.py
```

Viewer plus local UDP smoke test:

```bash
python teleoperation/wuji/viewers/retarget_eval_mujoco_wuji.py --bind_port 5014
python teleoperation/wuji/bridge/send_wuji_test_qpos_udp.py --target_port 5014
```

Windows Rokoko / glove input bridge:

```bash
python teleoperation/wuji/bridge/send_wuji_qpos_udp.py \
  --config teleoperation/wuji/configs/right_hand_wuji_glove_ik.json
```

Hammer-nail recording task:

```bash
python scripts/record_demos_zarr.py \
  --exp_name hammer_nail_wuji \
  --env_hz=60 \
  --show_sim_cameras=False
```

## Notes

The first Wuji XML path is generated from UniDex URDF assets. The generator
creates a MuJoCo compile-friendly URDF/XML cache and applies small inertial
floor values for tiny URDF links so MuJoCo can compile the model robustly.
