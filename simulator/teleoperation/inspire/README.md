# Inspire Teleoperation

This package is the dedicated home for Inspire hand teleoperation code.

## Current Status

- canonical `inspire_right` profile is a 6D active-qpos layout
- local UniDex Inspire right-hand URDF / mesh assets are copied under `assets/right/`
- distal finger joints are mimic joints and are not sent over UDP
- Panda-mounted Inspire XML is generated by `tools/generate_panda_inspire_xml.py`
- `hammer_nail_inspire` is registered for DexJoCo recording
- `bridge/send_inspire_qpos_udp.py` forwards Windows Rokoko/glove input to 6D Inspire qpos

## Commands

Regenerate the Panda-mounted XML:

```bash
python teleoperation/inspire/tools/generate_panda_inspire_xml.py
```

Standalone qpos viewer:

```bash
python teleoperation/inspire/viewers/retarget_eval_mujoco_inspire.py
```

Viewer plus local UDP smoke test:

```bash
python teleoperation/inspire/viewers/retarget_eval_mujoco_inspire.py --bind_port 5014
python teleoperation/inspire/bridge/send_inspire_test_qpos_udp.py --target_port 5014
```

Windows Rokoko / glove input bridge:

```bash
python teleoperation/inspire/bridge/send_inspire_qpos_udp.py \
  --config teleoperation/inspire/configs/right_hand_inspire_glove_ik.json
```

Hammer-nail recording task:

```bash
python scripts/record_demos_zarr.py \
  --exp_name hammer_nail_inspire \
  --env_hz=60 \
  --show_sim_cameras=False
```
